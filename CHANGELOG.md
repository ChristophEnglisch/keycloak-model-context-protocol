## [1.0.0](https://github.com/ChristophEnglisch/keycloak-model-context-protocol/compare/v0.0.2...v1.0.0) (2026-10-24)


### ⚠ BREAKING CHANGES

* Tools are renamed to `<domain>_<verb>` (`create-user` → `user_create`, `delete-user` → `user_delete`, `list-realms` → `realm_list`, `list-users` → `user_search`). Credentials must be configured explicitly; the `admin`/`admin` fallback is gone, and `KEYCLOAK_ADMIN`/`KEYCLOAK_ADMIN_PASSWORD` are deprecated in favour of `KEYCLOAK_USERNAME`/`KEYCLOAK_PASSWORD` or `KEYCLOAK_CLIENT_ID`/`KEYCLOAK_CLIENT_SECRET`. Destructive tools require an explicit confirmation through their `confirm` parameter. Node.js 22 or newer is required. See the [1.0 upgrade guide](https://github.com/ChristophEnglisch/keycloak-model-context-protocol/blob/main/docs/migration-1.0.md).

## 0.0.2

Released 2025-01-08.
- Renamed the binary to `keycloak-model-context-protocol` to match the npm package name.
- Documentation updates for the published npm package.

Four tools: `create-user`, `delete-user`, `list-realms`, `list-users`. Known problems fixed in 1.0.0: missing shebang line (the binary failed to start), global realm state, default credentials.

## 0.0.1

Released 2025-01-06.
- First public version: MCP server with four tools (`create-user`, `delete-user`, `list-realms`, `list-users`) on stdio, configured through `KEYCLOAK_URL`, `KEYCLOAK_ADMIN` and `KEYCLOAK_ADMIN_PASSWORD`.
- GitHub Actions workflow for publishing to npm.
